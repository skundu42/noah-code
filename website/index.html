Systems Architecture

Engineered from the kernel boundary up.

Every layer in Noah Code is built for multi-hour repository work: typed Python CodeAct execution, deny-by-default OS sandboxes, isolated Git worktrees, and crash-safe transactional storage.

NVIDIA NOOA Runtime

Python CodeAct, Not Fragile JSON Tool Loops

Instead of burning 6+ LLM roundtrips on brittle JSON tool-call schemas, Noah expresses turns as persistent, typed Python cells with AST syntax preflight, exact-preimage Match anchors, and atomic multi-file apply_patch edits. 

# 1 turn: parallel reads + anchored edit + immediate LSP & pytest check
src, spec = await asyncio.gather(
    self.ws.read("src/auth/tokens.py"),
    self.ws.read("tests/test_tokens.py"),
)
await self.ws.edit(
    "src/auth/tokens.py",
    Match("leeway=0", "leeway=CLOCK_SKEW_SECONDS"),  # Exact preimage check
)
check = await self.ws.bash("pytest -q tests/test_tokens.py")
Fail-Closed Containment

OS-Native Kernel Sandboxing

Generated Python cells never mount your workspace directly. They execute in a spawned worker confined by macOS Seatbelt (sandbox-exec) or Linux Landlock + seccomp, crossing a narrow permission-gated IPC broker.

Isolated Concurrency

Parallel Subagents & Linked Git Worktrees

Fan out concurrent specialists via task.orchestrate(..., isolate=True) or launch phased /team build|review|investigate workflows. Background writers get clean linked Git worktrees from HEAD while F4 gives live diff, apply, follow_up, and stop controls.

-91.4% Uncached Tail Tokens

Token-Efficient Prompt-Cache Architecture

Most agents mutate their system prompt on every turn (injecting timestamps, git status, or todo mutations), invalidating KV prompt caches. Noah partitions a 100% static Role.SYSTEM prefix, strips ANSI/spinner noise, and compacts stale outputs via disk-backed pointer eviction.

Naive Agent Loop (mutated system prompt + raw ANSI tail) 4,820 uncached tok / step
Noah Code v2.2 (immutable Role.SYSTEM + appended delta tail) 415 uncached tok / step (-91.4%)
