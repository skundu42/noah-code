# Noah Code v2.1.0

Noah Code `v2.1.0` fixes silent functional edge cases across automatic compaction, prompt caching, MCP session pooling, and ACP streaming, scales Git checkpoints and SQLite/undo persistence to large repositories, completes end-to-end isolated worktree workflows, and decomposes the TUI and host runtime.

## Compaction, prompt caching, streaming & MCP persistence

- Fixed `CodingSessionSummarizer` automatic background compaction on `nooa==0.0.12` by routing summary forks through `LeanPredictStrategy` (`ISOLATED_PREDICT_CONTEXT`) on `_lightweight_llm`, spilling/evicting oversized unspilled `PythonOutput` payloads, and keeping token-budget subscriptions active across turns.
- Added `CachedMarkdownBlockFormatter` for the default `"lean"` strategy to partition static system blocks ahead of `CacheBoundary()` and dynamic `<context>` tails, restored `prefix=True` static metadata across SQLite session snapshot restores, and updated `UsageTracker.observe_prefix` to measure cached-prefix stability up to `CacheBoundary`.
- Added live SSE streaming for OpenAI `ResponsesClient` routes (`with_model_streaming`) and explicit host truncation recovery notices on partial `finish_reason="length"` prose replies.
- Added persistent task-safe `stdio` MCP session pooling with automatic broken-pipe reconnection, mapped `oauth_scopes` / `oauth_callback_port` to `nooa` OAuth fields, filtered incompatible `nemo.*` built-in skills, and gated `self.skills.activate` fail-closed through the sandbox broker.
- Added live ACP `agent_thought_chunk` reasoning streaming with committed-event deduplication and non-fatal `replay_gap` handling (`ServiceUI` default replay buffer raised to `4096`).

## Security & sandboxing hardening

- Scrubbed `NOAH_CODE_SERVER_TOKEN`, hydrated credentials, and provider preset API keys from child shell sessions, background processes, LSP servers, and lifecycle/tool hooks while preserving in-process `os.environ` hydration; added `build_macos_workspace_command_profile` Seatbelt SBPL generation.
- Closed unquoted subshell `(...)` and brace-group `{ ...; }` parsing gaps in `PermissionEngine` across all deny, secret-token, env-dump, and interpreter rules; added `bun`, `deno`, `tsx`, `ts-node`, `lua`, and `luajit` interpreter guards; and permitted safe `python -m unittest` runs under `--auto`.
- Eliminated the runtime `os.umask(0)` race in `WorkspaceTools` via `/proc/self/status` and startup umask capture.

## Performance & large-repository scalability

- Upgraded `CheckpointManager.capture()` to `O(changed files)` via shadow-index + stat-sidecar + `git diff-index` delta staging (capping untracked blobs at 20 MB, keeping untracked files unstaged on `restore()`, and cleaning up checkpoint refs on session deletion).
- Switched `RuntimeStateStore` to a persistent thread-safe SQLite WAL connection (`synchronous=NORMAL`), moved file-journal undo pre/post bytes into content-addressed `<session>/blobs/<sha256>` storage, and buffered JSONL telemetry writes.
- Kept a persistent `CodexAppServer` per `CodexClient` with cached CLI binary verification, released `BudgetedLLM` locks across network `acall()` requests so parallel subagents (`run_many`, `/team`) execute concurrently, and added RFC 7231 HTTP-date `Retry-After` parsing plus `aclose()` cleanup.

## Verification, repo map, worktrees, service & TUI

- Switched foreground `ws.run` to `run_stream` for live output chunks, preserved file-journal `/undo` across clean verification commands, added `/undo --checkpoint`, ignored coverage/build cache artifacts in `CheckLedger` staleness checks, and allowed passing suite checks to supersede prior failed runs of the same `(label, cwd)`.
- Upgraded `RepositoryMap` with multi-language symbol extraction (Python `Class.method` + params, Rust `pub`/`pub(crate)`, Go receiver methods, TS/JS `export const`, Ruby, Java/C/C++) and cross-file reference centrality ranking.
- Completed isolated child worktree workflows with `include_dirty` seeding, `task.diff`, journaled `task.apply`, `task.cleanup`, and background subagent `WAIT` wakeups; added canonical Git-toplevel shared (`LOCK_SH`) `plan`-mode workspace leases, `--restrict-workspace` service scoping, lazy CLI startup, and `noah run --attach URL`.
- Extracted `ui/clipboard.py`, `ui/modals.py`, `ui/diff_screen.py`, and `host_commands.py`; added transcript row-count LRU caching, resize debouncing, wrapped-diff hunk navigation, native PNG clipboard image paste, multi-module evaluation benchmarks (`event-pipeline`, `build-graph`), Python `3.14` packaging metadata (`>=3.12,<3.15`), and streamlined single-job CI.
