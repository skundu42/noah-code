# Noah Code v0.8.0

Coordinate specialist teams from the terminal, track their assignments and handoffs, and make
permission decisions in a compact dialog. The command menu now uses aligned columns and readable
selection colors without hyperlink underlines.

## Coordinated teams

- Press `F9` or enter `/team` to choose Build, Review, or Investigate. The launcher keeps the
  objective editable in the composer and preserves displaced drafts through `Alt+Z`.
- `/team build OBJECTIVE` explores and plans in parallel, implements the change, then performs
  an independent review. Review and Investigate use read-only specialists, including synthesis.
- Team phases validate and authorize every role before work starts. Failed assignments and
  requests for input stop subsequent phases, with reports retained for the parent agent.
- Teams share session budgets and approvals. Read-only assignments can run concurrently;
  workspace writers use the existing serialized mutation lane. Cancellation drains peer agents
  before releasing that lane.
- Custom workflows can use `await self.task.team(objective, workflow="build")`. Existing
  `run`, `run_many`, and `collaborate` interfaces remain available.

## A more useful terminal interface

- `F4` and `/work` open a searchable live work panel. Filter all work, active assignments, or
  work needing attention; inspect objectives, team phases, and result previews.
- Requests for input and failures appear first. Refreshes preserve the selected assignment
  and reading position, and narrow terminals place results below the work list.
- Permission dialogs fit their content instead of occupying 80% of the terminal. Long targets
  remain scrollable, the session pattern stays visible, and `D` expands the reason and rule.
  The `1`, `2`, `3`, and `Esc` shortcuts remain, with Reject focused by default.
- Command suggestions have aligned names and descriptions, muted argument hints, and a subtle
  full-row selection. Mouse clicks, keyboard completion, and Unicode-width alignment work
  across terminal sizes.
- The welcome screen offers direct shortcuts to teams, change review, and previous sessions.

## Reliability and permissions

- Read-only delegated agents cannot switch into build mode or modify shared plan and memory
  files, including through an automatically approved plan transition.
- Queued or invalid team requests no longer generate completion receipts from a previous run.
- Team status records include workflow, phase, and team identifiers; displayed assignments use
  the user's objective instead of internal prompt scaffolding.

## Upgrade

```bash
noah update
```

Start a team with:

```text
/team review Check the current changes for regressions
```
