# Noah Code v2.2.0

Noah Code `v2.2.0` introduces zero-typing coding and OpenRouter model selection, parallel multi-subagent orchestration with live TUI telemetry, native Claude skills/commands/agents and 1-click MCP setup, `/resume` for picking up any of the last 3 repository chats, hierarchical `CLAUDE.md` / `AGENTS.md` instruction adherence, major harness token-efficiency gains, 16 TUI upgrades, and an interactive static landing page (`website/`).

## Zero-typing coding & OpenRouter model picker (`Ctrl+L`, `/model`)

- Added `noah_code.model_catalog` with curated 2025–2026 mainstream coding models across Anthropic (`claude-sonnet-5.5`, `claude-opus-5.5`, `claude-sonnet-4-6`, `claude-opus-4-6`), OpenAI (`gpt-5.3-codex`, `gpt-5.2-codex`, `gpt-6.1`, `gpt-5.4`, `o3`), Google (`gemini-4-hydrogen`, `gemini-3.8-pro-preview`, `gemini-2.5-pro`), Qwen (`qwen3-coder-next`, `qwen3-coder-plus`), DeepSeek (`deepseek-v4.1-flash`, `deepseek-v4`, `deepseek-v3.2`), xAI (`grok-build-0.1`, `grok-code-fast-1`), Mistral (`devstral-2512`), Z.ai (`glm-5.3`, `glm-5.1`), and Moonshot (`kimi-k2.7-code`, `kimi-k2.5`).
- Included all OpenRouter `openai/*` and `anthropic/*` routes plus native OpenRouter coding routers (`openrouter/auto-code`, `openrouter/pareto-code`, `openrouter/auto`), added live `https://openrouter.ai/api/v1/models` discovery with tool/modality filtering, and hydrated context-window metadata on `StreamingLLM`.
- Added `★ Popular coding models (quick pick)` in `Ctrl+L` and `Ctrl+P` for 1-step cross-provider model switching without typing model IDs.

## Parallel multi-subagent orchestration & live TUI strip

- Added `self.task.orchestrate(objective, subtasks, isolate=False, lead=None)` to fan out up to 12 concurrent subagents with upfront batch permission checks, optional `lead` synthesis, and isolated Git worktrees (`isolate=True`) so multiple writable subagents edit concurrently and merge non-conflicting patches back into the workspace.
- Streamed throttled live child tool-step telemetry (`current_action`, `step_count`, `isolated`, `phase`) into a dedicated `#subagent-strip` above the working banner, the `#context-rail` sidebar, and `WorkLedgerScreen` (`F4` / `Alt+I`).

## Claude skills, `.claude` compatibility & 1-click MCP connections

- Extended skill, command, and agent discovery to load `~/.claude/skills/*/SKILL.md` and `.claude/skills/*/SKILL.md` (with or without `name:` or YAML frontmatter, plus `when_to_use` and `allowed-tools`), `~/.claude/commands/*.md` and `.claude/commands/**/*.md` (including namespaced `/dir:cmd`), and `~/.claude/agents/*.md` + fail-closed `.claude/agents/*.md`; enabled `/skill-name` slash invocation alongside `$skill-name`.
- Added 12 built-in 1-click MCP presets (`context7`, `playwright`, `filesystem`, `fetch`, `memory`, `sequential-thinking`, `github`, `postgres`, `brave-search`, `linear`, `sentry`, `cloudflare-docs`), 1-click external MCP import from Claude Code / Claude Desktop / Cursor configs, auto-detected `/mcp add NAME <url-or-cmd>`, and `noah mcp {list,presets,add,preset,import,remove}` CLI subcommands.

## `/resume` last-3-chats picker & `--resume` CLI flag

- Added `/resume [1|2|3|SESSION_ID]`, `ResumeSessionPicker` (instant `1`/`2`/`3` keybinds, relative age, model badge, and read-only SQLite last-message previews), `Ctrl+P` palette entry, and `noah --resume` to jump directly back into any of the last 3 meaningful chats in the current repository.

## `CLAUDE.md` / `AGENTS.md` adherence, token efficiency & 16 TUI upgrades

- Added hierarchical outer-to-inner discovery (`~/.agents/AGENTS.md`, `~/.claude/CLAUDE.md`, Git-root-to-workspace `AGENTS.md`/`CLAUDE.md`/`.local`/`.override`), `@relative/path` doc imports inside `CLAUDE.md`, inode deduplication, and progressive scoped subdirectory rule injection when reading or editing nested packages.
- Moved static agent/skill instructions into the cached `Role.SYSTEM` prefix, compacted wire state/formatter blocks, stripped ANSI/spinner noise from shell output, and evicted superseded workspace snapshots (`-23.1%` to `-26.8%` initial prompt tokens; `-82.6%` to `-91.4%` uncached `<context>` tail per step).
- Upgraded the Textual TUI with coalesced 30 Hz markdown streaming, intraline diff review (`Ctrl+D`) with hunk stage/revert (`G`/`H`) and split/unified toggle (`S`), live context utilization gauge (`ctx Xk/Yk`), `$EDITOR` composer (`Ctrl+E`), transcript search (`Ctrl+F`), code-block copy (`Alt+C`), inline `QuestionModal`, and a WCAG AAA `daylight` light theme; added the interactive static landing page under `website/`.
