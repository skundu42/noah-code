# Noah Code v0.2.0

This release turns Noah Code into a more capable, responsive coding agent while keeping its
NOOA-based execution path compact and token efficient.

## Highlights

- Added lazy LSP navigation for definitions, implementations, references, symbols, hover details,
  diagnostics, rename previews, and changed-file symbol summaries, backed by an mtime-cached
  repository map.
- Added atomic multi-file patches with exact preimage validation, rollback, compact diffs,
  immediate diagnostics, concurrent-change detection, and undo-journal integration.
- Upgraded `/diff` into a keyboard-driven review workflow with staged and unstaged file trees,
  line counts, per-file patches, validation state, changed symbols, revert, and checkpoint undo.
- Added an owned background-process manager for development servers, watchers, interactive input,
  cursor-based log deltas, bounded runtimes, and process-group shutdown.
- Added guided provider, API-key, model, and reasoning-effort setup inside `/model`, with support
  for OpenAI, Anthropic, OpenRouter, NVIDIA, and other OpenAI-compatible providers.
- Added searchable skill and MCP setup flows with Codex- and Claude-compatible skill discovery,
  lazy MCP connections, and simpler extension management.

## Interface and efficiency

- Improved terminal text and Markdown rendering, live slash-command selection, keyboard mode
  switching, compact activity presentation, and clearer in-progress feedback.
- Added `fast`, `balanced`, and `deep` efficiency profiles, compact NOOA trajectory rendering,
  bounded reopenable tool previews, batched repository inspection, and cache-friendly context
  refreshes.
- Added `/tokens` reporting for inspecting prompt-cache, model-wait, tool-output, and estimated
  token usage.
- Upgraded the runtime integration to NOOA 0.0.9.

## Reliability

- Hardened background-process output draining, lifecycle transitions, input cleanup, and
  cross-platform timing behavior.
- Expanded the hermetic suite to 173 tests across Python 3.12 and 3.13, with Linux and macOS smoke
  coverage on arm64 and x86_64.
- Kept public installation binary-only and removed duplicated NOOA version pins from CI and release
  smoke tests.

## Upgrade

Existing managed installations can run:

```bash
noah update
```

New installations can use the one-command installer from the README.
