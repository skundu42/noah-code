# Noah Code v2.0.0

Noah Code `v2.0.0` upgrades the agent runtime to **NOOA `0.0.12`**, delivers comprehensive security and tool hardening across local, Git, LSP, web, and service boundaries, and sharpens the Textual TUI experience.

## NOOA 0.0.12 runtime & model streaming

- Upgraded `nooa` and `nooa-cli` dependencies (`nooa==0.0.12`, `nooa-cli==0.0.12`, plus `nooa[mcp]` and `nooa[tracing]`), updating event usage (`LLMUsage`), parsed response tracking (`LLMResponse.parsed`), and hermetic test isolation.
- Improved `StreamingLLM` cancellation handling (`_Call` / `_ObservedStream`) so cancelling a model turn promptly closes the active underlying transport stream (`aclose()` / `close()`) even under shielded async provider tasks.

## Textual TUI & Daylight theme

- Added the **`daylight`** light theme alongside the existing themes while keeping `atom-one-dark` as the default.
- Upgraded `FilteredPicker` with multi-token fuzzy scoring across command, provider, skill, and model pickers, and added `@@` hunk styling plus a `c` copy-patch shortcut in `DiffReviewScreen`.
- Hardened Rich markup rendering (`markup=False` and escaped button shortcut labels) across dynamic banners, approvals, and modals (`OnboardingScreen`, `QuestionModal`, `ConfirmationModal`, `TextPromptModal`, `DiffReviewScreen`) so paths and errors with brackets never raise `MarkupError`.
- Made `OnboardingScreen`, `QuestionModal`, and `ConfirmationModal` fit `80×24` terminals without clipping primary controls, preserved non-destructive mouse copy on `Ctrl+C`, switched timeline/activity IDs to monotonic sequence counters (`itertools.count`), cleaned up transient activity/stream state on cancellation, fixed cursor-aware `@mention` completion, enabled multi-page history loading, synchronized transcript selection across eviction/resize, and auto-cleared unread counters on scroll-to-end.

## Security, permissions, Git/LSP & runtime hardening

- Enforced strict workspace path confinement in workspace tools, required explicit confirmation on `plan -> build` transitions (`exit_to_build`), and constrained untrusted project custom commands from escalating modes or shadowing built-in commands.
- Hardened `WEBFETCH` redirect-hop approvals and `_is_public_unicast` SSRF validation, validated GitHub PR CLI targets with `DEVNULL`/timeout subprocess guards, shared `parse_porcelain_z` across Git/LSP/TUI, added JSON-RPC server request responses + UTF-16 column positioning + deleted-file `didClose` sync in LSP tools, preserved shell exit codes across `{ set +x; }` + `SIGINT` timeout interruption in process tools, and guarded MCP calls even when no runtime store is attached.
- Exported newline-preserving `redact_secrets` shared with telemetry attribute filtering, added FIFO generation duration pairing, tracked active-turn budget clocks, and tightened service/ACP reload and multi-subscriber handling.

## CLI, installer & self-update

- Removed the `nc` console script entry point so POSIX `netcat` is never shadowed; added a subcommand summary to `noah --help`, fixed `noah config show --auto` to clear saved `yolo`, added path/workspace support on `checkpoints list` and `sessions show/delete`, respected `NOAH_CODE_MODEL` in `--console` mode, and validated workspaces/sessions before persisting first-run defaults.
- Separated notice vs auto-install rate-limit timestamps (`auto_checked_at` / `checked_at`) with `~/.cargo/bin/uv` lookup in the updater, and hardened `install.sh` with `--https-only --secure-protocol=TLSv1_2`, `< /dev/null` stdin guards, and signal-preserving cleanup traps.

## Upgrade

```bash
noah update
```

curl -LsSf https://github.com/skundu42/noah-code/releases/latest/download/install.sh | sh
